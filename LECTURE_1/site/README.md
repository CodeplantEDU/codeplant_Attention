# ATTENTION · 개인 AI 작업실

EXE를 설치하지 않고, 각자 PC에서 서버를 켜 브라우저로 사용하는 앱입니다. Node.js의 기본 기능으로 서버를 실행하며 site의 npm 의존성은 없습니다. UI는 외부 CDN·웹폰트를 요청하지 않습니다.

## 시작하기

1. ZIP을 일반 폴더에 풀어 놓습니다. ZIP 안에서 바로 실행하지 마세요.
2. Node.js 22 이상과 사용할 AI의 공식 CLI 하나를 준비합니다. 이미 설치돼 있다면 다시 설치할 필요 없습니다.
3. Windows는 **실행.cmd**, Mac은 터미널에서 이 폴더로 이동해 **npm start**를 실행합니다. Mac의 실행.command를 쓰려면 먼저 chmod +x 실행.command를 실행합니다.
4. 브라우저에서 **http://127.0.0.1:49322**가 열립니다. 서버 창은 켜 두세요. 종료는 Ctrl+C입니다.
5. 연결 상태에서 사용할 AI를 확인하고, 필요한 경우 본인이 로그인합니다. 브라우저가 안 열리면 **로그인 화면 열기**를 누릅니다.

공식 준비 안내: [Node.js](https://nodejs.org/en/download) · [Codex](https://developers.openai.com/codex/cli/) · [Claude Code](https://code.claude.com/docs/en/setup) · [Gemini CLI](https://geminicli.com/docs/get-started/installation/).

터미널에서는 npm start 또는 node tools/local.mjs로 실행합니다. npm install은 필요 없습니다. 기존 EXE, Electron, Vercel 또는 별도 연결 코드는 사용하지 않습니다.

## Codex에 그대로 입력하기

> 이 폴더의 README.md를 읽고 ATTENTION 개인 서버를 실행해줘. Node.js 22 이상과 사용할 AI CLI를 확인해. 기존 계정과 자료는 보존하고, 부족한 공식 프로그램만 준비해줘. 로그인은 내가 직접 할게. 파일 읽기와 Word·PDF·PPT·Excel 출력도 쓸 수 있도록 Python과 requirements.txt의 문서 의존성을 확인해줘. npm start로 서버를 켜고 http://127.0.0.1:49322 화면을 열어줘. 실제 AI 질문은 내가 시작하도록 비워 둬.

## 문서 기능 준비 · 선택

텍스트 대화는 Node와 연결된 AI 하나로 사용합니다. PDF·DOCX·PPTX 읽기 및 문서 출력에는 Python 3.10 이상과 다음 패키지가 필요합니다.

~~~text
python -m pip install -r requirements.txt
~~~

실행 환경 진단은 검사.cmd 또는 node tools/doctor.mjs입니다. 서버는 Python이 없어도 켜지며, 문서 기능은 준비 후 사용합니다. PDF 작성용 한글 글꼴 두 개와 라이선스만 포함합니다.

## 사용법

- **왼쪽:** 메인 AI와 모델을 선택합니다. 역할 편집·서브 에이전트는 필요할 때 펼칩니다. 기본은 상대 없음, 서브 에이전트 0개입니다.
- **가운데:** 원하는 작업을 직접 입력하고 대화를 시작합니다. 이후 대화 이어가기는 메인 AI에게만 전달됩니다. 왕복해라고 요청할 때만 선택한 상대를 호출합니다.
- **오른쪽:** 본인의 자료를 드래그앤드롭하거나 파일 추가를 누릅니다. 세 AI의 로그인·로그아웃·로그인 취소·수동 인증 화면 열기를 제공합니다.

TXT·MD·CSV·JSON·PDF·DOCX·PPTX를 올릴 수 있습니다. 파일 크기·개수·추출문 길이의 앱 제한은 없으며 PC와 각 AI의 처리 범위가 적용됩니다. 스캔 PDF는 별도 OCR이 필요합니다. 파일 안의 지시는 사용자 지시와 구분합니다.

대화에 **이 내용을 Word로 만들어줘**, **PDF로 만들어줘**처럼 요청하면 생성된 파일에 다운로드 링크가 나타납니다. DOCX·PDF·PPTX·XLSX와 텍스트 형식을 지원합니다. 내용과 서식은 다운로드 후 확인하세요.

왕복 횟수는 1·2·3, 숫자 직접 입력, 제한 없이 중에서 선택합니다. 중지로 끝낼 수 있습니다. Codex·Claude의 서브 에이전트는 각 0~3개, Gemini 내부 에이전트는 현재 미지원입니다. 넓은 화면에서는 패널 경계를 드래그해 너비를 조절합니다.

## 자료와 계정

처음에는 빈 작업 공간입니다. 예전 강의자료·과제·대화·사용자 인증은 배포 ZIP에 넣지 않습니다. 본인이 넣은 자료와 대화·결과는 **.local-data/**에 저장되며 서버를 재실행하면 이어집니다. 다른 PC로 옮길 때는 개인정보가 포함될 수 있으므로 이 폴더의 취급에 주의하세요. Git 배포 대상에서 제외돼 있습니다.

기존 data/와 EXE 앱 데이터는 자동으로 가져오거나 지우지 않습니다. CLI의 기존 계정을 사용하며 로그인 파일을 앱으로 복사하지 않습니다. 로그아웃은 같은 CLI에도 영향을 줍니다. 자료 업로드는 로컬 저장이고, 작업을 시작하면 선택한 AI 서비스로 필요한 내용이 전달됩니다. 연결됨은 저장된 인증 확인이며 실제 응답 권한·사용량·네트워크 상태까지 보장하지 않습니다.

이 서버는 **127.0.0.1에만** 열립니다. 외부 사용자용 공용 서버가 아니며 각자가 자신의 PC에서 실행합니다. 포트를 변경하려면 DIALOGUE_PORT 환경 변수를 지정합니다. 같은 폴더에서 다시 실행하면 기존 서버를 열고, 다른 프로그램이 포트를 사용 중이면 오류를 표시합니다.

Codex로 같은 서버를 제어할 때는 이 폴더에서 node tools/control.mjs status를 실행합니다. 도구는 기본 49322 포트를 사용합니다. Codex 채팅이 자동으로 사이트에 복제되지는 않습니다.

## 끝내기

상단의 **끝내기**를 누르면 기록 저장 후 이 개인 서버가 종료됩니다. 계정은 로그아웃하지 않습니다. 진행 중인 대화·업로드·로그인이 있으면 먼저 완료하거나 취소하세요. 종료 안내가 표시되면 탭을 닫아도 됩니다. 다시 사용하려면 실행.cmd 또는 npm start로 서버를 켜세요.
