Windows: `CODEPLANT-ATTENTION-Windows.exe`를 실행하세요. 별도 설치 명령은 필요 없습니다.

Mac: `CODEPLANT-ATTENTION-Mac.dmg`를 열어 앱을 Applications로 옮겨 실행하세요. Apple Silicon과 Intel을 함께 지원하는 Universal 앱입니다.

1. 사용할 AI를 하나 이상 선택하고 **선택한 AI 준비**를 누릅니다. 처음에는 공식 도구를 다운로드하므로 인터넷이 필요합니다.
2. **대화 화면 열기**에서 각 AI의 **로그인**을 눌러 본인 브라우저에서 인증합니다.
3. 메인·상대·모델·역할을 선택해 자료를 드래그앤드롭하고 대화합니다. **Word로 만들어줘** 등으로 파일을 요청합니다.

Node와 문서 엔진은 앱에 포함됩니다. 사용자의 개인 기록·자료·인증은 배포 파일에 포함하지 않습니다. 계정 사용량은 각 서비스에 적용됩니다. 기존 CLI 로그인은 공식 CLI가 재사용할 수 있으며 로그아웃은 같은 PC의 해당 CLI에도 영향을 줍니다.

서명 인증서가 없는 배포본입니다. Windows SmartScreen 또는 macOS Gatekeeper에서 실행을 확인해야 할 수 있습니다. Mac은 시스템 설정 → 개인정보 보호 및 보안에서 차단된 앱의 **확인 없이 열기**를 사용할 수 있습니다. 보안 기능 전체를 끄지 마세요.

빌드 검증은 각 운영체제의 패키지 실행·화면 로드·DOCX/PDF/PPTX/XLSX 생성·PDF 텍스트 추출입니다. 실제 사용자 로그인과 유료 모델 호출은 자동 배포 테스트에서 수행하지 않습니다.
