## 독립 UI/UX 검수

사용자가 요청한 독립 UI/UX 검수 에이전트가 실제 브라우저에서 1440px·390px 화면, 단계 이동, 입력 오류, 저장·다시 열기, ZIP 다운로드, 키보드 조작, AI 제안 비교·적용·적용 취소를 확인했습니다. 세부 범위와 판단은 [검수자 보고](evidence/uiux-review.md)에 기록합니다.

검수 중 발견해 수정한 항목:

- 파일 선택 입력의 숨김 스타일이 풀려 가로 스크롤이 생기는 문제
- 미리보기의 스크립트 정책과 글꼴 CORS로 예시 동작·폰트가 차단되는 문제
- 잘못된 참고 주소에 색상·숫자 오류 안내가 표시되는 문제
- 마지막 선택 디자인과 정상 저장 상태가 새로고침 때 유지되지 않는 문제
- 규칙 탭의 방향키·Home·End 조작 누락
- 사용자 이름이 CSS 주석 안에 들어가는 경로 제거

저장 실패 복구는 브라우저에서 PUT 응답을 500으로 가로채는 **모의 실패**로 확인했습니다. 실제 디스크 고장이나 네트워크 단절을 만들지는 않았습니다. 정상 저장·새로고침·내보내기와 두 AI 호출은 실제 동작입니다.

## 미검증 범위

- macOS·Linux 실행, 새 수강생 PC의 첫 설치, 계정별 요금제·사용 한도와 모델 권한
- 로그인 터미널을 통한 새 로그인 절차: 기존 본인 로그인을 재사용했으며 로그아웃시키지 않았습니다.
- 스크린리더 전체 검사와 모든 배율·브라우저·입력장치 조합
- 실제 디스크 고장·정전·강제 프로세스 종료 중 저장, 외부 네트워크 배포
- 최종 Codex 스킬 제작과 스킬 적용 결과: 이번 서비스는 디자인 시스템 자료까지만 만듭니다.

공개 참조 URL의 내용 자동 수집, 이미지로부터 브랜드 추출, 다중 사용자 공용 서버와 협업 편집은 구현 범위에 포함하지 않았습니다.

## 로고·서체 상세 편집 추가 검수

로고·심볼·어두운 배경용 원본과 본문/제목 글꼴 업로드, 역할별 크기·굵기·행간·자간, 사용규칙·출처 기록을 추가했습니다. 확장 검수는 [독립 검수 보고](evidence/uiux-brand-review.md)와 [확장 AI 응답 기록](evidence/ai-brand-smoke.json)에 기록합니다. 초기 검수의 화면·시간과 후속 확장 검수를 구분해서 확인하세요.

확장 ZIP은 CRC 검사와 함께 압축 해제 후 file://로 열어 실제 업로드 본문/제목 글꼴 두 face가 loaded이고 콘솔 오류가 없음을 확인했습니다([기록](evidence/brand-export-check.json)). 업로드 응답을 지연시킨 뒤 다른 프로젝트로 이동하는 브라우저 검사에서도 양쪽 프로젝트의 fontAssets가 변경되지 않았습니다([기록](evidence/brand-switch-check.json)). 실제 정상 파일 업로드는 TTF 두 종류로 확인했고 OTF·WOFF·WOFF2·가변 글꼴의 실제 파일은 미검증입니다.
