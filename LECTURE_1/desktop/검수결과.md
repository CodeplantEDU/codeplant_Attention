## 0.7.1 Claude 수동 로그인 화면 열기

사용자는 이 PC에서는 Claude 인증 화면이 열리지만 다른 PC에서 자동으로 열리지 않을 때 쓸 수 있는 버튼을 요청했다. 개인 인증 파일을 사용하지 않는 임시 `CLAUDE_CONFIG_DIR`로 실제 Claude CLI를 실행해 인증 주소의 호스트가 `claude.com`인 것을 확인했다. 인증 주소의 쿼리·코드·토큰은 기록하지 않았고 계정 로그인은 완료하지 않았다.

서버의 인증 주소 인식 목록과 데스크톱의 공식 인증 주소 허용 목록에 `claude.com`을 추가했다. 기존 **로그인 화면 열기** 버튼이 이 주소에서도 나타나며, 사용자가 클릭하면 Electron이 공식 인증 주소를 외부 브라우저로 연다. 별도 자동 열기나 Codex·Gemini 로그인 방식 변경은 추가하지 않았다.

Node 테스트 **63개**가 통과했다. 실제 렌더러 이벤트를 실행해 Claude 로그인 중 버튼 표시·활성화·정확한 AI로 브라우저 열기 요청·인증 종료 후 숨김을 확인했다. 실제 데스크톱 API 계약에서 현재 Claude 호스트를 사용하며 유사 도메인은 거부한다.

[0.7.1 빌드·설치 검증 39123671425](https://github.com/CodeplantEDU/codeplant_Attention/actions/runs/39123671425)의 Windows 패키징, 별도 Windows의 실제 설치·시작 로그인 화면·문서 처리·제거 및 자료 보존 검사, 공개 릴리스가 모두 통과했다. 앱 코드 기준은 `8db2f6e`이다. 기존 로그인 계정에서의 실제 인증 완료나 다른 사용자의 특정 PC 브라우저는 검사하지 않았다.

## 0.7.0 Windows 설치형 전환

Windows 배포를 설치 마법사 `CODEPLANT-ATTENTION-Setup.exe`로 변경했다. 사용자별 설치 위치 선택, 바탕화면·시작 메뉴 바로가기, 설치된 앱 등록과 프로그램 제거를 제공한다. 사용자 자료는 제거 시 자동 삭제하지 않는다. Mac은 기존 0.6.2 DMG를 유지한다.

시작 화면의 `허용되지 않은 요청`과 연결되는 IPC 검사에서 파일 URL 문자열을 그대로 비교하던 부분을 수정했다. 한글·공백·URL 인코딩·Windows 경로의 대소문자를 정규화하고, 요청 창·메인 프레임·파일 경로 검증은 유지한다. 사용자가 오류를 겪은 PC의 전체 오류 기록은 제공되지 않았으므로 그 PC의 원인을 원격으로 확정한 것은 아니다.

Node 테스트 **62개**가 통과했다. [Windows 설치 실행 검사 39123166617](https://github.com/CodeplantEDU/codeplant_Attention/actions/runs/39123166617)에서 별도 Windows 러너에 한글·공백·`#`가 있는 경로로 실제 설치하고, 격리한 사용자 자료 경로와 전역 Node·Python·AI CLI가 없는 PATH로 실행했다. 시작 로그인 화면·세 AI 연결 버튼·미로그인 차단·실제 preload IPC·로컬 서버·10MB/60,000자 초과 업로드·DOCX/PDF/PPTX/XLSX 생성·PDF 추출이 통과했다. 개인 계정 로그인과 실제 모델 호출은 수행하지 않았다.

[최종 설치 검증 39123307336](https://github.com/CodeplantEDU/codeplant_Attention/actions/runs/39123307336)의 Windows 검사가 통과했다. 실제 설치 마법사, 한글 설치 경로에서의 시작 화면·문서 처리, 바탕화면·시작 메뉴 바로가기의 실제 대상 파일, 설치된 앱 등록, 프로그램 제거와 자료 보존을 확인했다. 사용자 PC의 기존 계정은 건드리지 않았다. 별도 Windows VM과 격리한 자료 폴더에서 검사한 결과이며, 사용자가 문제를 겪은 특정 PC에서 재검증한 결과는 아니다.

## 0.6.2 참고자료 제한 해제

파일당 10MB·선택 5개·추출문 60,000자와 PDF 페이지·PPTX 슬라이드 수 제한을 화면·서버·추출기에서 제거했다. 업로드 HTTP 본문 크기와 추출 프로세스 stdout 버퍼의 기존 제한도 함께 해제했다. 형식·인코딩·중복 자료·경로·압축 폭탄·XML 엔티티 검증은 유지한다. 하드웨어 메모리 및 각 AI의 입력 처리 범위를 넘어서는 동작까지 보장하지 않는다.

데스크톱 11개, site 49개, Python 추출 5개, 합계 **65개**가 통과했다. 공개 합성 자료로 **10MB 초과 실제 HTTP 업로드**, **6개 선택 및 7번째 자료로 대화 이어가기**, **원문의 마지막 부분까지 모의 모델 입력에 전달**, **60,000자 초과 DOCX**, **301페이지 PDF·301슬라이드 PPTX**를 검사했다. 실제 사용자 자료나 모델 호출은 사용하지 않았다.

PyInstaller 인터프리터·라이브러리 런타임은 재사용하되, 패키징 시 `_internal/extract.py`를 현재 추출기 소스로 갱신한다. 패키지 실행 검사에서도 10MB·60,000자 초과 텍스트 업로드를 수행해 오래된 추출기가 섞이지 않는지 확인한다.

- 실제 개인 계정의 신규 로그인·로그아웃과 유료 모델 응답은 이 배포본 검사에서 실행하지 않았다. 인증은 사용자가 공식 브라우저 화면에서 완료한다. 계정별 모델 권한·사용량은 실제 요청에서 확인한다.
- 초기 Intel 에뮬레이션 검사는 완료되지 않았다. 이를 통과로 계산하지 않고, 이후 **네이티브 Intel 러너에서 배포 DMG 자체를 실행해 통과**한 결과를 사용했다.
- 현재 사용자 PC의 숨김 창 캡처 검사에서는 Electron `capturePage`의 `UnknownVizError`가 발생했다. 이 로컬 검사 전체를 통과로 표시하지 않는다. Windows 빌드 환경에서는 같은 최종 패키지의 화면·문서 처리가 통과했으며, 실패한 캡처는 `--smoke-test` 전용 코드다. 일반 대화·파일 생성에서 화면 캡처 API를 사용하지 않는다.
- Windows·Apple 개발자 인증서와 notarization은 적용하지 않았다. 첫 실행 시 OS 확인이 필요할 수 있다. 보안 기능을 일괄 해제하지 않는다.
- 개인 PC의 재부팅 후 동작, 모든 OS 버전, 조직 계정·학교 관리 정책은 별도 실사용 확인 대상이다.
