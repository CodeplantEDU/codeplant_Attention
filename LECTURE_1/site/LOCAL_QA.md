# 개인 서버 0.8.0 검수 · 2026-10-18

## 변경

EXE·Electron·Vercel 연결 없이 Node 서버와 브라우저로 실행한다. 화면은 중앙 작업 입력·대화, 왼쪽 접을 수 있는 AI 설정·기록, 오른쪽 사용자 자료·계정 상태로 재구성했다. 시스템 글꼴을 사용하며 이전 강의 예시 버튼·기본 서브 에이전트 두 개를 제거했다.

새 작업 공간은 `.local-data/`, 기본 포트는 49322다. 기존 `data/` 및 설치형 앱의 자료는 이동·삭제하지 않았다. 같은 폴더에서 두 번째 실행 시 서버 식별값을 확인하고 기존 창을 연다. 다른 서비스의 포트를 빼앗지 않는다. 바인딩은 127.0.0.1만 사용한다.

## 확인한 결과

- Node 회귀 검사 **65개 통과**. 로그인·취소·로그아웃, 메인/상대/서브 에이전트, 모델·왕복 설정, 대용량 자료, 패널 크기 조절, 새 작업 공간의 자료 격리, 중앙 입력 폼의 연결 및 필수 UI 제어 존재를 검사했다.
- 실제 새 화면에서 빈 기록·빈 자료·서브 에이전트 0개와 기존 CLI 계정 상태를 확인했다. 개인 계정을 로그인·로그아웃하거나 모델을 호출하지 않았다.
- 별도 모의 AI 서버의 실제 브라우저에서 공개 합성 TXT를 올려 추출·체크 상태를 확인하고 중앙 입력에서 작업을 시작했다. 후속 대화에 Word 작성을 요청해 실제 DOCX 다운로드 링크를 클릭했다. 내려받은 파일의 ZIP 구조와 `word/document.xml`의 시험 본문을 확인했다. 모의 답변과 실제 파일 생성은 구분한다.
- 바탕화면 `국민대학교_바탕/ATTENTION_개인서버`의 배포 폴더로 실행 위치를 옮겼다. 이 새 서버의 중복 실행 안내와 127.0.0.1:49322 바인딩을 확인했다. 이전 서버는 건드리지 않았으며 에이전트가 만든 시험 서버만 종료했다.
- ZIP은 26개 파일, **2,457,249 bytes**다. 배포 목록을 명시해 개인 기록·자료·계정·로그·node_modules·EXE·강의자료를 제외했다. PDF 출력에 필요한 한글 글꼴 2개와 라이선스를 포함한다. SHA256: `72a23ac7b601da38618c07545c89e323742ce3f39179b30777dbfdfddeea7201`.

## 검증 범위

이 PC의 Windows·Node 24.14.0·기존 Python 문서 의존성으로 실행했다. 다른 PC의 신규 설치와 실제 계정 인증 완료·과금 모델 응답·Mac 실행은 미검증이다. 브라우저의 임시 viewport 변경이 실제 화면 크기에 반영되지 않아 모바일 실화면 검사를 통과로 표시하지 않는다. 좁은 화면용 CSS는 포함하지만 별도 기기에서 확인이 필요하다.

전체 소스 저장소에는 이전 작업이 남지만 새 ZIP에 포함하지 않는다. 자료와 결과의 용량은 `.local-data/` 사용량에 따라 늘어난다. 런타임·CLI·Python 패키지는 각자 PC에 준비하며 ZIP 크기에 포함하지 않는다.
