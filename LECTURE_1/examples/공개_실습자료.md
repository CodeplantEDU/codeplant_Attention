# 공개 실습 조건

이 문서는 기능 시연을 위해 만든 가상 과제 조건이다. 실제 기관의 성과나 사업 실적이 아니다.

- 대상: AI를 처음 사용하는 성인.
- 수업 시간: 총 120분.
- 목적: 메인 AI가 상대 AI의 반론을 받아 결과를 고치는 과정을 관찰한다.
- 필수 시연: 자료 업로드, 메인 AI 선택, 역할 분담, 상대 AI 반론, 후속 질문, 기록 내려받기.
- 판단 기준: 시간 합계 120분, 자료와 제안 구분, 사람에게 남은 선택 명시.
- 측정하지 않은 것: 정확도 상승률, 시간 절약률, 학습 성취도.

참고자료에 없는 일정·통계·교육 효과를 실제 사실처럼 만들지 않는다.
