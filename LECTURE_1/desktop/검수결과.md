패키지 생성과 Windows·Apple Silicon 검사는 [빌드 39112408293](https://github.com/CodeplantEDU/codeplant_Attention/actions/runs/39112408293), 같은 파일의 네이티브 Intel 검사와 공개 릴리스는 [검증·배포 39113338277](https://github.com/CodeplantEDU/codeplant_Attention/actions/runs/39113338277)에 기록돼 있다. 바이너리의 앱 코드 기준 커밋은 `ee6fb37`이며, `64b21bc`는 이미 만들어진 패키지의 Intel 검사·릴리스 조건을 수정한 워크플로다.

Windows와 Apple Silicon 빌드 환경에서는 앱이 사용하는 설치 함수로 세 공식 CLI를 실제 다운로드하고 실행했다. 버전은 Codex `0.163.0`, Claude Code `2.1.302`, Gemini `0.64.0`이다. 사용자 PC의 전역 설치를 덮어쓰지 않고 앱 전용 경로에 설치한다.

추가 검사: 기존 site Node 테스트 47개, 데스크톱 경로·입력 경계 테스트 5개, Python 문서 생성 3개·자료 추출 4개가 통과했다. 자동 테스트의 모델 응답은 모의 응답이며, 네이티브 패키지 검사는 실제 렌더러·서버·문서 엔진을 실행했다.

## 검증 범위와 남은 확인

- 실제 개인 계정의 신규 로그인·로그아웃과 유료 모델 응답은 이 배포본 검사에서 실행하지 않았다. 인증은 사용자가 공식 브라우저 화면에서 완료한다. 계정별 모델 권한·사용량은 실제 요청에서 확인한다.
- 초기 Intel 에뮬레이션 검사는 완료되지 않았다. 이를 통과로 계산하지 않고, 이후 **네이티브 Intel 러너에서 배포 DMG 자체를 실행해 통과**한 결과를 사용했다.
- 현재 사용자 PC의 숨김 창 캡처 검사에서는 Electron `capturePage`의 `UnknownVizError`가 발생했다. 이 로컬 검사 전체를 통과로 표시하지 않는다. Windows 빌드 환경에서는 같은 최종 패키지의 화면·문서 처리가 통과했으며, 실패한 캡처는 `--smoke-test` 전용 코드다. 일반 대화·파일 생성에서 화면 캡처 API를 사용하지 않는다.
- Windows·Apple 개발자 인증서와 notarization은 적용하지 않았다. 첫 실행 시 OS 확인이 필요할 수 있다. 보안 기능을 일괄 해제하지 않는다.
- 개인 PC의 재부팅 후 동작, 모든 OS 버전, 조직 계정·학교 관리 정책은 별도 실사용 확인 대상이다.

## 기존 자료와 공개 사이트

기존 `127.0.0.1:49321` 서비스는 재시작하지 않았다. 별도 포터블 검사 종료 후에도 저장 작업 **7개**, 업로드 **9개**, 실행 중인 작업 없음이 유지됐다. 새 앱의 `data/`는 사용자 앱 데이터 경로를 사용하며, 기존 서비스가 실행 중이면 그 서비스를 재사용한다. 기존 기록을 자동 이동·삭제하지 않는다.
