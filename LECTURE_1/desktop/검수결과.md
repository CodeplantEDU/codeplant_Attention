0.6.0은 도구가 이미 설치됐거나 기존 서버가 있으면 준비 화면을 건너뛰었으며, 준비 화면 자체에도 계정 로그인 버튼이 없었다. 0.6.1은 앱 시작과 재실행 시 AI 로그인 창을 먼저 표시한다. AI별 로그인·로그아웃·취소·공식 로그인 화면 다시 열기, 미설치 AI의 준비 후 로그인, 연결된 계정 보존, 한 계정 연결 후 대화 시작을 추가했다. 로컬 제어 토큰과 개인 기록은 로그인 창 IPC에 전달하지 않는다.

## 검증 범위와 남은 확인

- 실제 개인 계정의 신규 로그인·로그아웃과 유료 모델 응답은 이 배포본 검사에서 실행하지 않았다. 인증은 사용자가 공식 브라우저 화면에서 완료한다. 계정별 모델 권한·사용량은 실제 요청에서 확인한다.
- 초기 Intel 에뮬레이션 검사는 완료되지 않았다. 이를 통과로 계산하지 않고, 이후 **네이티브 Intel 러너에서 배포 DMG 자체를 실행해 통과**한 결과를 사용했다.
- 현재 사용자 PC의 숨김 창 캡처 검사에서는 Electron `capturePage`의 `UnknownVizError`가 발생했다. 이 로컬 검사 전체를 통과로 표시하지 않는다. Windows 빌드 환경에서는 같은 최종 패키지의 화면·문서 처리가 통과했으며, 실패한 캡처는 `--smoke-test` 전용 코드다. 일반 대화·파일 생성에서 화면 캡처 API를 사용하지 않는다.
- Windows·Apple 개발자 인증서와 notarization은 적용하지 않았다. 첫 실행 시 OS 확인이 필요할 수 있다. 보안 기능을 일괄 해제하지 않는다.
- 개인 PC의 재부팅 후 동작, 모든 OS 버전, 조직 계정·학교 관리 정책은 별도 실사용 확인 대상이다.
