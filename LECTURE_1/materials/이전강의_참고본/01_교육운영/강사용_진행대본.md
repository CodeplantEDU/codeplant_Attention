# ATTENTION AI 대화 특강 강사용 진행 대본

120분 핵심 시연형. 수업의 중심은 Codex가 실제 Claude 회신을 받고 자기 답변을 다시 전달하는 과정이다. Gemini는 같은 방식의 합류를 보여준다. 보고서 작성·재무 분석은 확장 소재다.

## 01 Codex가 Claude와 Gemini를 불러 대화하게 하기

시간: 0~2분

설명: ATTENTION 추가 특강 · 2시간 핵심 시연형

진행·입력: Codex 작업 폴더와 대화 기록을 먼저 연다.

확인: 강의 주제가 AI 간 대화 연결임을 말한다.

막힐 때: 연결 구조 그림을 사용한다.

## 02 오늘 보여줄 장면

시간: 2~5분

설명: Codex 질문 → Claude 반론 → Codex 답변 → Claude 재답변

진행·입력: 대화 파일의 발신자와 수신자를 차례로 가리킨다.

확인: 한 번의 답변 받기와 왕복 대화를 구분한다.

막힐 때: 재생 대본을 교육용 예시로 표시해 읽는다.

## 03 누가 대화를 진행할까

확인: Codex 혼자 외부 모델 역할을 연기하지 않음을 확인한다.

막힐 때: 각 역할을 한 문장씩 읽는다.

공식·사례 근거: https://code.claude.com/docs/en/headless https://geminicli.com/docs/cli/headless/
