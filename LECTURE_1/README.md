# LECTURE 1 · AI끼리 대화하게 만들기

Codex 또는 Claude를 메인으로 선택하고, 양쪽의 역할을 선택·직접 작성합니다. 각 AI에 네이티브 서브 에이전트를 0~3개 추가·삭제해 초안과 검토를 분담할 수 있습니다. 상대 AI가 검토하면 메인 AI가 수용·반박·보류 이유를 설명하며 답을 고칩니다. 파일 드래그앤드롭과 후속 대화도 지원합니다.

## 두 가지 사용법

**사이트에서 대화:** `site/실행.cmd`를 열고 메인 AI·양쪽의 역할과 서브 에이전트·왕복 수를 고릅니다. 왕복은 숫자 직접 입력·제한 없음도 지원합니다. 자료를 드래그앤드롭하고 추출문을 확인한 뒤 시작합니다. 가운데 아래의 **대화 이어가기**는 기본적으로 메인 AI와만 대화합니다. “왕복해”, “3회 왕복해”라고 지시할 때만 상대 AI를 부릅니다.

**Codex에서 지시:** 이 저장소를 Codex의 작업 폴더로 엽니다. 아래 지시문으로 실행한 뒤, Codex에 자료 업로드와 작업 시작을 요청할 수도 있습니다. 화면은 같은 로컬 서비스의 상태를 보여줍니다. 이 Codex 채팅의 내용이 사이트에 자동 동기화되는 구조는 아니며, Codex가 `tools/control.mjs`로 선택한 지시와 자료만 전달합니다.

```text
AGENTS.md와 LECTURE_1/site/README.md를 읽고 AI 대화 스튜디오를 실행해줘.
필요 프로그램·기존 로그인을 확인하고 http://127.0.0.1:49321 화면을 열어줘.
기존 data 폴더는 보존해. 실제 AI 대화는 내가 시작하도록 화면까지만 준비해줘.
```

## 처음 한 번 준비

Windows에서 Node.js 22 이상, Python 3.10 이상, Codex CLI, Claude Code를 준비합니다. Codex와 Claude는 각자 본인 계정으로 로그인합니다. 별도 API 키나 MCP 서버는 기본 실행에 필요하지 않습니다.

`site` 폴더에서:

```powershell
python -m pip install -r requirements.txt
```

그다음 `실행.cmd`를 엽니다. 설치부터 맡기고 싶으면 [복사용 지시문](docs/Codex에_이렇게_입력.md)의 첫 번째 문장을 사용하세요.

## 자료와 기록

- 지원: TXT·MD·CSV·JSON·PDF·DOCX·PPTX. 파일당 10MB, 한 작업 최대 5개, 추출 텍스트 합계 60,000자.
- PDF·문서는 텍스트만 추출합니다. 이미지·복잡한 표·스캔 문서의 내용은 별도 확인이 필요합니다. 읽지 못한 문서는 오류나 경고로 표시합니다.
- 업로드 자체는 이 PC에 저장합니다. 새 작업과 명시적인 왕복 요청은 두 서비스에 전달하고, 일반 후속 요청은 메인 서비스에만 전달합니다.
- 후속은 기존 대화·자료·역할을 유지합니다. “왕복해”라고 하면 기존 횟수를, “5회 왕복해”라고 하면 해당 횟수를 사용합니다. “제한 없이 왕복해”도 가능합니다. 종료 조건이 비어 있는 무제한 대화는 직접 중지해야 합니다.
- **AI 모델 선택**에서 Codex·Claude의 모델을 각각 고릅니다. Codex는 CLI 목록, Claude는 Opus·Sonnet·Haiku 별칭을 제공하며 직접 입력도 가능합니다. 작업 시작 시 적용하고 서브 에이전트는 부모 모델을 상속합니다.
- **“이 내용을 Word로 만들어줘”**라고 대화에 입력하면 실제 DOCX를 작성하고 다운로드 링크를 보여줍니다. 별도 생성 버튼은 없습니다. PDF·PPTX·XLSX·텍스트 파일도 형식을 지정해 요청할 수 있습니다. 수정 요청은 새 파일로 저장합니다.
- 패널 사이 경계선을 드래그해 좌·중·우 너비를 조절합니다. 폭은 브라우저에 저장되며 초기화할 수 있습니다.
