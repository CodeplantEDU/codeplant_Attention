# ATTENTION · 개인 AI 작업실

EXE를 설치하지 않고, 각자 PC에서 서버를 켜 브라우저로 사용하는 앱입니다. Node.js의 기본 기능으로 서버를 실행하며 site의 npm 의존성은 없습니다. UI는 외부 CDN·웹폰트를 요청하지 않습니다.

## 시작하기

**Codex가 메인인 권장 방식:** Windows는 **자동준비.cmd**를 실행합니다. Node.js가 없으면 공식 ZIP·SHA256 검증 후 앱 폴더에 준비합니다. Claude·Antigravity CLI와 문서 패키지는 없는 것만 설치하고 `attention-codex` 스킬과 개인 서버·화면을 준비합니다. Python이 없으면 WinGet 사용자 범위 설치를 시도합니다. WinGet이 없거나 설치 권한·네트워크가 막히면 오류를 표시합니다. 보안 설정이나 인증을 우회하지 않습니다. 로그인은 본인이 완료합니다.

새 Codex 대화에서 다음처럼 입력하세요.

> $attention-codex 필요한 도구를 자동으로 준비하고 작업실을 열어줘. Codex가 메인을 맡고 Claude와 Antigravity를 상대로 [내 과제]를 진행해. 각 AI의 실제 답변·자료·진행과 오류 조치를 화면에 바로 보여줘.

이미 Node가 있으면 `node tools/bootstrap.mjs`도 같은 준비를 실행합니다. `--providers claude`로 선택한 AI만 준비하고 `--skip-documents`로 문서 도구를 생략할 수 있습니다. `--check-only`는 설치·서버 실행 없이 확인합니다. Mac의 Node/Python 자체 설치는 자동화하지 않았습니다. 준비 스크립트는 AI에게 질문하지 않습니다.

앱이 없는 다른 Windows PC에서는 스킬의 `scripts/setup.ps1`이 공개 GitHub 고정 릴리스와 공식 API의 SHA256을 확인해 앱을 내려받아 준비합니다. 기존 개인 자료는 배포 대상에서 제외하고 보존합니다. CLI와 문서 의존성은 필요한 경우 인터넷으로 내려받으므로 처음 실행에는 시간이 걸립니다.

1. ZIP을 일반 폴더에 풀어 놓습니다. ZIP 안에서 바로 실행하지 마세요.
2. Node.js 22 이상을 준비합니다. AI CLI는 화면 오른쪽의 설치 버튼으로 준비합니다. 이미 설치돼 있다면 설치됨으로 표시합니다.
3. Windows는 **실행.cmd**, Mac은 터미널에서 이 폴더로 이동해 **npm start**를 실행합니다. Mac의 실행.command를 쓰려면 먼저 chmod +x 실행.command를 실행합니다.
4. 브라우저에서 **http://127.0.0.1:49322**가 열립니다. 서버 창은 켜 두세요. 종료는 Ctrl+C입니다.
5. 연결 상태에서 사용할 AI를 확인하고, 필요한 경우 본인이 로그인합니다. 브라우저가 안 열리면 **로그인 화면 열기**를 누릅니다.

공식 준비 안내: [Node.js](https://nodejs.org/en/download) · [Codex](https://developers.openai.com/codex/cli/) · [Claude Code](https://code.claude.com/docs/en/setup) · [Antigravity CLI](https://www.antigravity.google/docs/install?tab=cli).

터미널에서는 npm start 또는 node tools/local.mjs로 실행합니다. npm install은 필요 없습니다. 기존 EXE, Electron, Vercel 또는 별도 연결 코드는 사용하지 않습니다.

## Codex에 그대로 입력하기

스킬이 설치되면 `$attention-codex`로 요청합니다. 이 모드의 메인은 **현재 Codex 채팅**이며 Codex CLI를 다시 호출하지 않습니다. Codex가 작성한 공개 진행·초안·판단을 뷰어에 게시하고 상대 CLI의 실제 답변·에이전트 이벤트를 도착할 때 표시합니다. 채팅 전체나 내부 추론이 자동으로 복제되는 방식은 아닙니다. 후속 요청도 원래 Codex 채팅에서 합니다.

실패하면 해당 AI·단계·오류 유형·확인된 종료 코드·조치가 남습니다. 인증·사용량·모델·네트워크·시간 초과·실행 옵션 등을 분류하고 원시 stderr·토큰은 게시하지 않습니다. Codex는 `diagnose`와 `doctor`를 읽어 조치하고, 일시적 오류만 필요할 때 한 번 재시도합니다. 모든 오류를 자동으로 해결한다는 보장은 없으며 사용량·인증·지원되지 않는 환경은 사용자의 조치가 필요할 수 있습니다.

직접 제어 명령은 `node tools/control.mjs` 다음에 `task 요청.json`, `publish 작업ID 기록.json`, `consult 작업ID 상대요청.json`, `watch 작업ID 20`, `inspect 작업ID`, `diagnose 작업ID`, `files 작업ID 파일.json`, `finish 작업ID 최종.md`입니다. JSON 예제와 순서는 [Codex 스킬](skills/attention-codex/SKILL.md)을 참고하세요. 실행 중인 호출은 기존 `stop 작업ID`로 중지합니다.

> 이 폴더의 README.md를 읽고 ATTENTION 개인 서버를 실행해줘. Node.js 22 이상과 사용할 AI CLI를 확인해. 기존 계정과 자료는 보존하고, 부족한 공식 프로그램만 준비해줘. 로그인은 내가 직접 할게. 파일 읽기와 Word·PDF·PPT·Excel 출력도 쓸 수 있도록 Python과 requirements.txt의 문서 의존성을 확인해줘. npm start로 서버를 켜고 http://127.0.0.1:49322 화면을 열어줘. 실제 AI 질문은 내가 시작하도록 비워 둬.

## 문서 기능 준비 · 선택

텍스트 대화는 Node와 연결된 AI 하나로 사용합니다. PDF·DOCX·PPTX 읽기 및 문서 출력에는 Python 3.10 이상과 다음 패키지가 필요합니다.

~~~text
python -m pip install -r requirements.txt
~~~

실행 환경 진단은 검사.cmd 또는 node tools/doctor.mjs입니다. 서버는 Python이 없어도 켜지며, 문서 기능은 준비 후 사용합니다. PDF 작성용 한글 글꼴 두 개와 라이선스만 포함합니다.

## 사용법

- **왼쪽:** 메인 AI와 모델을 선택합니다. 역할 편집·서브 에이전트는 필요할 때 펼칩니다. 기본은 상대 없음, 서브 에이전트 0개입니다. 첫 상대를 선택한 뒤 **+ 상대 AI 추가**를 누르면 메인을 제외한 나머지 AI도 추가합니다. 상대별 역할·모델·서브 에이전트를 따로 설정하고, 두 번째 상대 제거로 다시 줄일 수 있습니다.
- **가운데:** 원하는 작업을 직접 입력하고 대화를 시작합니다. 이후 대화 이어가기는 메인 AI에게만 전달됩니다. 왕복해라고 요청할 때만 선택한 상대를 호출합니다.
- **오른쪽:** 본인의 자료를 드래그앤드롭하거나 파일 추가를 누릅니다. 세 AI의 로그인·로그아웃·로그인 취소·수동 인증 화면 열기를 제공합니다.

TXT·MD·CSV·JSON·PDF·DOCX·PPTX를 올릴 수 있습니다. 파일 크기·개수·추출문 길이의 앱 제한은 없으며 PC와 각 AI의 처리 범위가 적용됩니다. 스캔 PDF는 별도 OCR이 필요합니다. 파일 안의 지시는 사용자 지시와 구분합니다.

대화에 **이 내용을 Word로 만들어줘**, **PDF로 만들어줘**처럼 요청하면 생성된 파일에 다운로드 링크가 나타납니다. DOCX·PDF·PPTX·XLSX와 텍스트 형식을 지원합니다. 내용과 서식은 다운로드 후 확인하세요.

상대가 두 개이면 같은 메인 초안을 각 상대가 검토하고, 메인이 두 회신을 종합하는 것까지를 1회 왕복으로 셉니다. 선택한 모든 상대의 로그인이 필요하며, 상대 없이 메인 하나만 사용할 수도 있습니다.

왕복 횟수는 1·2·3, 숫자 직접 입력, 제한 없이 중에서 선택합니다. 중지로 끝낼 수 있습니다. Codex·Claude의 서브 에이전트는 각 0~3개, Antigravity 내부 에이전트는 현재 미지원입니다. 넓은 화면에서는 패널 경계를 드래그해 너비를 조절합니다.

## 자료와 계정

처음에는 빈 작업 공간입니다. 예전 강의자료·과제·대화·사용자 인증은 배포 ZIP에 넣지 않습니다. 본인이 넣은 자료와 대화·결과는 **.local-data/**에 저장되며 서버를 재실행하면 이어집니다. 다른 PC로 옮길 때는 개인정보가 포함될 수 있으므로 이 폴더의 취급에 주의하세요. Git 배포 대상에서 제외돼 있습니다.

기존 data/와 EXE 앱 데이터는 자동으로 가져오거나 지우지 않습니다. CLI의 기존 계정을 사용하며 로그인 파일을 앱으로 복사하지 않습니다. 로그아웃은 같은 CLI에도 영향을 줍니다. 자료 업로드는 로컬 저장이고, 작업을 시작하면 선택한 AI 서비스로 필요한 내용이 전달됩니다. 연결됨은 저장된 인증 확인이며 실제 응답 권한·사용량·네트워크 상태까지 보장하지 않습니다.

이 서버는 **127.0.0.1에만** 열립니다. 외부 사용자용 공용 서버가 아니며 각자가 자신의 PC에서 실행합니다. 포트를 변경하려면 DIALOGUE_PORT 환경 변수를 지정합니다. 같은 폴더에서 다시 실행하면 기존 서버를 열고, 다른 프로그램이 포트를 사용 중이면 오류를 표시합니다.

Codex로 같은 서버를 제어할 때는 이 폴더에서 node tools/control.mjs status를 실행합니다. 도구는 기본 49322 포트를 사용합니다. Codex 채팅이 자동으로 사이트에 복제되지는 않습니다.

## 끝내기

상단의 **끝내기**를 누르면 기록 저장 후 이 개인 서버가 종료됩니다. 계정은 로그아웃하지 않습니다. 진행 중인 대화·업로드·로그인이 있으면 먼저 완료하거나 취소하세요. 종료 안내가 표시되면 탭을 닫아도 됩니다. 다시 사용하려면 실행.cmd 또는 npm start로 서버를 켜세요.

## 화면에서 도구 설치

오른쪽 연결 상태에서 원하는 AI의 **설치**를 누릅니다. 설치 중에는 상태를 표시하고 완료 후 **로그인** 버튼이 나타납니다. 이미 설치된 CLI는 그대로 사용하며, 설치됨으로 표시합니다. 실패하면 **다시 설치**를 누릅니다. 로그인은 본인이 공식 인증 화면에서 완료합니다.

Codex 0.163.0과 Claude Code 2.1.302는 공식 npm 패키지를 사용합니다. Antigravity는 공식 업데이트 매니페스트의 네이티브 agy 바이너리를 내려받아 SHA512를 검증한 뒤 .local-data/cli/antigravity에 설치합니다. 모델 목록은 agy models의 실제 출력을 사용합니다. 전역 설치·계정·시스템 PATH를 덮어쓰지 않습니다. Node 설치에 포함된 npm이 필요하며, 첫 다운로드에는 인터넷이 필요합니다. 설치 파일과 캐시는 최초 다운로드 이후 디스크 공간을 사용하며 배포 ZIP에는 포함하지 않습니다.

**문서 도구 설치**는 Python이 준비된 PC에서 requirements.txt의 패키지를 .local-data/python-packages에 설치합니다. 시스템의 다른 Python 프로젝트를 변경하지 않고 이 서버 프로세스에만 적용합니다. Python 자체가 없으면 옆의 Python 준비 안내에서 공식 설치를 마친 뒤 다시 누르세요. 설치 중에는 대화·계정 변경·서버 끝내기를 잠시 막습니다.

## Antigravity 전환

세 번째 연결은 Gemini CLI 대신 **Antigravity CLI(agy)**입니다. 기존 대화와 인증 파일은 보존하며 이전 Gemini 작업을 Antigravity가 답한 것으로 바꾸지 않습니다. 새 작업에서 Antigravity를 선택하세요. Antigravity 모델에 Gemini 또는 Claude라는 이름이 표시돼도 실행하는 프로그램과 인증은 agy입니다.

Windows에서 로그인·로그아웃 버튼은 공식 CLI의 대화형 터미널을 열어 인증 절차를 진행하며, 읽기 전용 /usage 결과로 완료를 확인합니다. 로그인은 터미널이 여는 공식 브라우저에서 완료하세요. Mac은 터미널에서 agy로 로그인하고 /logout으로 로그아웃한 뒤 새로 확인하세요. 내부 에이전트 연결은 현재 지원하지 않습니다.

호출은 공식 stream-json 입력·출력을 사용합니다. 계획 모드와 슬래시 명령 확장 비활성화로 실행하며 --dangerously-skip-permissions는 사용하지 않습니다. 공식 사양: https://www.antigravity.google/docs/cli/headless/
