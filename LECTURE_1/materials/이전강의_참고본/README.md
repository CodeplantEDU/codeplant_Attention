이 참고본은 Codex 진행·Claude/Gemini 확장과 이전 전달 도구를 설명합니다. 현재 사이트는 Codex·Claude와 Gemini CLI 어댑터를 제공하며, 하나만 연결해도 사용할 수 있습니다. Gemini 실제 응답은 Google 로그인 후 확인해야 합니다. 파일 속 `03_대화실습`·`05_사례`·기존 경로는 이 참고본 제작 당시의 구성이며, 현재 프로그램의 실행 경로가 아닙니다.

지금 강의는 [최신 2시간 운영안](../../docs/2시간_시연_운영안.md)과 [Codex 복사용 지시문](../../docs/Codex에_이렇게_입력.md)을 기준으로 진행하세요. Gemini 실행·새 UI 기능을 이 PPT에서 검증했다고 설명하지 않습니다. 실제 개인 세션 로그와 대학교 원본 수업자료는 배포하지 않습니다.
