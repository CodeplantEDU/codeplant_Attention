# Codex가 Claude와 Gemini를 불러 대화하기

## 1 강의 목적

Codex를 메인 진행자로 사용해 실제 Claude Code를 호출하고, 회신을 읽고, Codex의 답변을 다시 보내 왕복 대화를 이어가는 방법을 보여준다. Gemini는 앞선 대화를 전달받아 다른 관점으로 합류한다. 사용자가 확정한 2시간 핵심 시연형으로 구성했다. 기존 회사 분석은 AI 대화의 소재로 축소했다.

대상은 Attention 참여자이며 파일 열기와 AI 채팅 경험이 있다는 가정으로 설계했다. 전공·코딩 경험은 필수로 두지 않는다. 인원·날짜·장소·예산은 미정이다. 수강생에게 새 계정 구매나 API 키 발급을 요구하지 않는다.

## 2 학습 목표와 확인 기준

학습자는 Codex가 실제 외부 AI를 부르는 경로를 설명하고, 첫 회신을 읽어 다음 질문을 작성하는 과정을 따라갈 수 있다. 종료 시 실제 회신·다음 Codex 발언·전송 범위·남은 사람 판단이 있는지 확인한다. 핵심 성취는 보고서 파일 수가 아니라 실제 연결과 왕복 대화다.

중간에는 첫 회신에서 수용할 점과 되물을 질문을 각각 하나 찾게 한다. 다수가 구분하지 못하면 11번 슬라이드와 실제 회신을 다시 읽는다. 이는 수업 운영을 위한 제안 기준이며 실제 교육 성과를 주장한 것이 아니다.

## 4 필요한 프로그램과 준비

강사는 Codex, 본인 계정으로 로그인한 Claude Code, Python 3.10 이상, 인터넷을 준비한다. Gemini 합류 시 Gemini CLI와 Node.js 20 이상을 준비한다. 학생은 강사 화면과 제공 파일만으로 참여할 수 있다. 계정·사용량·요금·설치 지원 범위는 수업 직전 각 공식 안내에서 확인한다.

D-1에는 ZIP을 풀고 check·prepare를 실행해 패킷을 확인한다. 강사 본인 계정으로 공개 연습 자료의 첫 호출과 재호출을 점검한다. Gemini 설치·인증이 안 되면 합류를 완료했다고 말하지 않고 구조 설명과 표시된 재생 자료를 쓴다. 실시간 답이 90초 이상 걸리면 저장된 실제 회신으로 진행하고 호출 상태를 이후 확인한다.

## 5 시연의 실제 동작

Codex가 메시지를 작성하고 relay.py를 실행한다. 전달 도구는 고정 공개 자료와 이전 대화, 새 메시지를 패킷으로 만들어 CLI의 표준 입력에 보낸다. 회신을 받은 뒤 Codex가 직접 다음 답변을 써서 다시 호출한다. 서로 다른 서비스가 직접 네트워크로 대화하는 구성이 아니라 Codex가 중간에서 전달하는 구성이다. 프로그램이 자동으로 모델의 다음 발언을 쓰지 않는다.

대화 기억은 이전 메시지를 다음 패킷에 다시 담는 방식이다. CLI 고유 세션을 재개하는 심화 방법과 구분한다. 기본 두 왕복 뒤 종료하고 도구 자체의 한도는 외부 호출 6회다. 합의가 생겨도 원문 검증과 사람의 전략 선택을 생략하지 않는다.

## 6 MCP와 교육 범위

기본 실습은 CLI 호출이다. MCP 어댑터로 외부 모델 호출 도구를 노출하는 구조는 짧게 설명하며 이 패키지에 구현했다고 주장하지 않는다. 공식 문서 MCP는 문서 읽기 서버이며 Claude·Gemini 대화 서버가 아니다. 새 MCP 서버 개발·API 키 발급·모든 계정 로그인 실습은 2시간의 핵심 시연 범위에서 제외한다.

## 7 장점과 확인 한계

한 Codex 작업에서 질문·회신·반박을 이어가고 발신자와 수정 이유를 남길 수 있다. 같은 자료를 앱마다 수동 복사하는 작업을 줄이도록 설계했다. 시간 절약률과 정확도 개선률은 측정하지 않았다. 각 모델의 성능 우열을 수업 역할로 단정하지 않는다.

공식 출처는 04_연결안내/공식출처.md에 있다. 대학 강의 원본·사적 녹취·계정 정보는 배포하지 않는다. 새 실제 대화의 실행 범위와 Gemini 미실행 여부는 05_사례/실제대화/실행기록.md에 기록한다. 수강생 계정과 강의장 네트워크, 네이티브 PowerPoint 표시는 별도 사전 확인이 필요하다.
