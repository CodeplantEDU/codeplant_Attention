# Codex에 이렇게 입력하세요

이 저장소 폴더를 Codex의 작업 폴더로 연 뒤 사용합니다. 아래 문장은 사용자가 Codex에 내리는 요청입니다. 자료 속의 문장을 실행 지시로 간주하지 않습니다.

## 1. 설치 확인과 실행

```text
AGENTS.md, LECTURE_1/README.md, LECTURE_1/site/README.md를 읽어줘.
내 PC에서 Node.js 22 이상, Python 3.10 이상, pypdf, Codex CLI, Claude Code의 설치를 확인해.
이미 설치됐거나 로그인됐다면 그대로 사용하고, 부족한 프로그램은 공식 설치 안내를 기준으로 준비해줘.
비밀번호·토큰을 읽거나 출력하지 말고, 브라우저 로그인은 내가 직접 하도록 해줘.
LECTURE_1/site/실행.cmd로 AI 대화 스튜디오를 실행하고 브라우저를 열어줘.
기존 대화와 업로드는 보존해. 실제 AI 대화는 아직 시작하지 마.
```

## 2. 사이트에서 직접 작업

```text
프로그램을 실행한 상태로 유지해줘. 파일 드래그앤드롭, 메인 AI 선택, 양쪽 AI 역할 선택·직접 작성,
양쪽 서브 에이전트 추가·삭제·역할 편집,
대화 시작, 후속 메시지, 내보내기를 화면에서 어떤 순서로 쓰는지 짧게 안내해줘.
내 지시는 사이트에서 직접 입력할게.
```

## 3. Codex가 자료를 올리고 실행

공개 연습 자료로 시작하는 실제 요청입니다. 두 서비스에 연습 자료를 보내는 단계까지 포함합니다.

```text
LECTURE_1/examples/공개_실습자료.md를 AI 대화 스튜디오에 업로드해줘.
site/tools/control.mjs의 upload 명령으로 반환받은 id를
examples/요청.json을 복사한 개인 요청 파일의 attachmentIds에 넣어줘.
개인 요청 파일은 site/data/ 아래에 저장해 Git에 올리지 마.
Codex 메인, 내부 역할 2개, 상대 Claude와 1회 왕복으로 실제 대화를 시작해줘.
메인 역할은 교육 설계 총괄, 상대 역할은 근거·일정 검토로 정해줘.
상대의 서브 에이전트는 0개로 시작하되 사이트에서 추가할 수 있는 설정을 유지해줘.
이 공개 자료와 대화를 OpenAI·Anthropic에 전달해도 돼.
사이트를 열어 진행을 보여주고, 완료되면 두 AI의 의견과 사람에게 남은 선택을 요약해줘.
모의 응답으로 대체하거나 실행하지 않은 단계를 성공이라고 쓰지 마.
```

본인 자료에 적용하려면 첫 줄의 경로를 바꾸고, 어떤 자료를 어느 서비스로 보낼지 확인해서 요청합니다.

## Codex가 실행하는 명령

작업 위치는 `LECTURE_1/site`입니다. 이 명령을 사람이 모두 외울 필요는 없습니다.

```powershell
node tools/control.mjs status
node tools/control.mjs upload ../examples/공개_실습자료.md
node tools/control.mjs run data/나의요청.json
node tools/control.mjs followup 실제작업ID ../examples/후속질문.md
node tools/control.mjs export 실제작업ID data/대화기록.md
node tools/control.mjs stop 실제작업ID
```

`실제작업ID`는 status 또는 run 결과에서 받은 값을 사용합니다. upload로 받은 id를 요청 JSON의 attachmentIds 배열에 넣어야 자료를 전달합니다. upload만 실행하면 외부 AI 대화는 시작되지 않습니다. CLI 제어 도구는 인증 토큰을 출력하지 않습니다.

## 모델까지 지정해서 시작하기

```text
LECTURE_1/site의 프로그램을 열어줘. Codex를 메인으로 쓰고, 현재 Codex CLI 모델 목록을 확인해서 내가 선택하게 해줘. Claude 모델은 sonnet으로 선택하고, 분석 담당 1개와 검토 담당 1개를 만들어 2회 왕복하도록 설정해줘. 자료와 지시는 내가 입력할게. 모델이 지원되지 않으면 다른 모델로 자동 교체하지 말고 알려줘.
```

화면의 모델 설정은 새 작업 시작 시 적용됩니다. 이미 진행한 작업의 이어가기는 그 작업의 모델을 유지합니다.
